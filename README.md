# RAG Assistant - Строительные нормы РК

Интеллектуальный ассистент для работы со строительными нормами Республики Казахстан, использующий технологию RAG (Retrieval-Augmented Generation) и Self-RAG для точных ответов на вопросы по нормативным документам.

## 🚀 Быстрый старт для Windows

### Предварительные требования

1. **Python 3.8+** - [Скачать с python.org](https://www.python.org/downloads/)
   - При установке обязательно отметьте "Add Python to PATH"
   - Проверьте установку: `python --version`

2. **OpenAI API Key** - [Получить на platform.openai.com](https://platform.openai.com/api-keys)

### Установка и запуск

#### Способ 1: Автоматический запуск (рекомендуется)

1. **Скачайте проект** и распакуйте в любую папку
2. **Создайте файл `.env`** на основе `.env.template`:
   ```bash
   # Скопируйте .env.template в .env
   copy .env.template .env
   ```
3. **Отредактируйте `.env`** и добавьте ваш OpenAI API ключ:
   ```
   OPENAI_API_KEY=sk-your-actual-api-key-here
   ```
4. **Запустите приложение**:
   - **Через командную строку**: Дважды кликните на `run_app.bat`
   - **Через PowerShell**: Дважды кликните на `run_app.ps1`

#### Способ 2: Ручная установка

1. **Откройте командную строку** в папке проекта
2. **Установите зависимости**:
   ```cmd
   pip install -r requirements.txt
   ```
3. **Создайте необходимые папки**:
   ```cmd
   mkdir downloaded_pdfs
   mkdir vectordb
   ```
4. **Создайте файл `.env`** с вашим API ключом
5. **Запустите приложение**:
   ```cmd
   streamlit run app.py --server.port=8501 --server.address=localhost
   ```

## 🔧 Настройка

### Переменные окружения

Создайте файл `.env` на основе `.env.template`:

```env
# Обязательные настройки
OPENAI_API_KEY=your_openai_api_key_here

# Опциональные настройки Self-RAG
SELF_RAG_MODEL=gpt-4o-mini
SELF_RAG_TEMPERATURE=0
SELF_RAG_SEARCH_K=10
SELF_RAG_FETCH_K=30
SELF_RAG_SCORE_THRESHOLD=0.4
SELF_RAG_MAX_CONTEXT_CHUNKS=10
SELF_RAG_MAX_ROUNDS=2
```

### Добавление PDF документов

1. Поместите PDF файлы в папку `downloaded_pdfs/`
2. Перезапустите приложение
3. Система автоматически обработает новые документы

## 🎯 Использование

1. **Откройте браузер** по адресу `http://localhost:8501`
2. **Загрузите PDF документы** через интерфейс или поместите в папку `downloaded_pdfs/`
3. **Выберите режим**:
   - **Self-RAG** (рекомендуется): Самокритика и адаптивный поиск
   - **Обычный RAG**: Стандартный поиск по документам
4. **Задайте вопрос** и получите точный ответ с указанием источников

## 🔍 Возможности

- **Self-RAG**: Самокритика ответов и адаптивный поиск
- **Фильтрация по документам**: Ограничение поиска конкретным документом
- **Инкрементальная обработка**: Добавление новых PDF без пересоздания базы
- **Подробные источники**: Указание конкретных страниц и документов
- **Русскоязычный интерфейс**: Полностью локализованный интерфейс

## 🛠️ Устранение неполадок

### Проблемы с Python
```cmd
# Проверьте версию Python
python --version

# Если Python не найден, переустановите с опцией "Add to PATH"
```

### Проблемы с зависимостями
```cmd
# Обновите pip
python -m pip install --upgrade pip

# Переустановите зависимости
pip install -r requirements.txt --force-reinstall
```

### Проблемы с API ключом
- Убедитесь, что файл `.env` создан в корне проекта
- Проверьте правильность API ключа
- Убедитесь, что у вас есть доступ к OpenAI API

### Проблемы с PDF
- Убедитесь, что PDF файлы не повреждены
- Проверьте права доступа к папке `downloaded_pdfs/`
- Убедитесь, что PDF содержат текст (не сканы изображений)
